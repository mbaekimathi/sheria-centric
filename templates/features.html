Intake Layer — detailed module functions

Governs how new legal instructions are accepted, validated, and transformed into structured matter records.

  • Inputs: client identity, matter description, urgency, instruction documents.
  • Core functions: conflict prompts, onboarding checklists, advocate assignment, court metadata.
  • Outputs: approved matter record, initial timeline, document task list.

Work Layer — detailed module functions

The operational engine for filings, evidence management, and hearing readiness.

  • Inputs: active matters, files, hearing schedules, team assignments.
  • Core functions: version control, evidence indexing, task dependencies, escalations.
  • Outputs: hearing-ready files, completion logs, status updates.

Finance Layer — detailed module functions

Converts legal work into measurable financial outcomes with full billing transparency.

  • Inputs: billable activity, disbursements, retainer balances, milestones.
  • Core functions: invoicing, aging analysis, collection queues, financial visibility.
  • Outputs: invoices, payment statuses, collection actions, revenue reports.
